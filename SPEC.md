# 12. IMPRIMERIE PDF INTELLIGENTE

Cette fonctionnalité est essentielle.

L'application doit permettre de placer automatiquement plusieurs exemplaires d'une création sur une feuille.

Formats de papier :

- A4.
- A3.
- A5.
- Lettre US.
- Format personnalisé.

### Exemple

L'utilisateur crée une carte de visite de 85 × 55 mm.

Il demande 100 exemplaires.

L'application calcule le nombre de cartes pouvant tenir sur une feuille A4, selon les marges et espacements choisis.

Elle génère automatiquement un PDF contenant toutes les feuilles nécessaires.

### Fonctionnalités obligatoires

- Choix du format de papier.
- Orientation portrait ou paysage.
- Nombre d'exemplaires.
- Calcul automatique de la disposition.
- Marges personnalisables.
- Espacement entre les cartes.
- Traits de découpe.
- Fonds perdus.
- Gestion du recto verso.
- Prévisualisation des feuilles.
- Export PDF haute qualité.

Prévoir un moteur de calcul précis des dimensions en millimètres.

Ne pas utiliser une simple capture d'écran agrandie pour produire les PDF.

Conserver les éléments vectoriels lorsque cela est possible.

Vérifier que les cartes ne sont ni déformées ni coupées.

Prévoir des tests automatiques de disposition.
